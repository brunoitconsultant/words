> Document                  /* 2D byte-array    : holds documents                                       */
    [d]                     > document id       : fixed for now, 0, 1, 2
    [c]                     > char byte array   : ABCDEFGH...VWXYZ0...9


> Token                     /* 3D byte-array    : holds all doc terms                                   */
    [d]                     > document id       : reference to document
    [s]                     > sequence id       : incremental term counter
    [m]                     > metadata          : [0]   token sequence id
                                                : [1]   document id
                                                : [2]   token start pos
                                                : [3]   token length
                                                : [4]   token hash(djb2)


> Lexic                     /* 3D byte-array    : holds token frequency for each document               */
    [d]                     > document id       : reference to document
    [b]                     > bucket            : with colision control (term hash % 1000000)
    [m]                     > metadata          : [0]   token hash(djb2)
                                                : [1]   token counter
