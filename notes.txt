> Library:                                              /* stores books */
    two dimension byte-array
        [n] ABCDEFGHIFKLMNOPQRSTUVWXYZ0...9
> Token:                                                /* stores words in books */
    four dimension byte-array
        [0] id (auto-increment)
        [1] start
        [2] length
        [3] hash (djb2)
> Lexic:                                                /* stores word count */
    two dimension byte-array
        [0] derived from Token's hash, calculating % 100000 & clash conflit 
        [1] count
